一个可分发的技能包由六层组成。越往上越接近「契约」，越往下越接近「分发」。这张图不是格式清单，是责任划分：每一格都在回答同一个问题——拿到包的人凭什么能像作者一样用它？

LAYERSUBSYSTEMS ／ 每一格 = 一个必须写进包里的承诺
L5触发层

description

TRIGGER

能力—触发—前提三段式；给机器读，不是给人读。

50 WORDS

name / slug

IDENTITY

slug 取文件夹名；name 与文件夹保持一字不差。

requires

BINS / ENV

声明 node 18+ 与环境变量；消费方据此标灰缺依赖。

负向指引

NOTES

「exit 2 不是技能的错」——失败归属也参与触发决策。

L4契约层

退出码

EXIT CODES

0 / 1 / 2 / 3；按「下一步该做什么」分类，不按技术原因。

CONTRACT

管道分工

STDOUT/ERR

机器读 stdout（合法 JSON）；人读 stderr（诊断）。

可执行修复提示

HINT

地址 + cause code + 下一步动作（start.bat），拒绝堆栈。

诚实超时

TIMEOUT

超时 ≠ 任务失败：留下 record id，画廊可复用。

L3包体层

零依赖脚本

ZERO DEPS

Node 18 内置 fetch；无 npm install——安装即解压。

{baseDir} 占位

PORTABLE PATH

一切路径占位或协议相对；硬编码相对路径是 404 之源。

零密钥

NO SECRETS

密钥在服务配置里；技能只对本机 127.0.0.1 说话。

最小依赖面

3 ENDPOINTS

只钉 health / generations / polish 三个最稳端点。

L2分发层

CLI 发布

PUBLISH

login --device → inspect → publish + changelog。

API 发布

MULTIPART

clh_ token + POST /skills（payload JSON + files[]）。

安全扫描

SCAN ≈60s

publish ≠ 公开；轮询 /skills/{slug} 至 200 再验收。

限流礼仪

RATE LIMIT

读 3000/min/IP 免 token；写 300；429 尊重 Retry-After。

L1治理层

安装 ≠ 启用

DEFAULT OFF

script-bearing 默认停用，启用需人工确认。

RELEASE

分级

text-only / script

文本直用；脚本每次执行过受控审批。

出处三件套

PROVENANCE

requires 明示 + scan 展示 + 回链作者页。

卸载闭环

UNINSTALL

缓存目录与转换产物同步清理；lock 记版本来源。

L0风险层

7.1% 泄漏率

SNYK

密钥 / PII 入包：发布前 grep sk- / Bearer / 真实路径。

提示注入

INJECTION

SKILL.md 是给模型读的指令——分级与审批是唯一闸门。

更新投毒

UPDATE

lock 锁版本；更新是显式动作；内容寻址待做。

API 演进

DRIFT

适配器隔离协议变化；每版本跑验收清单。

WHY THIS SHAPE

上面三层决定「别人能不能用起来」，中间一层决定「能不能发出去」，下面两层决定「装到别人家后出了事算谁的」。所有技能事故几乎都发生在两层之间的缝隙：description 太窄没人触发、退出码缺失导致盲目重试、密钥顺手进了示例。

huajing-image-gen 全包 319 行：80 行文档 + 239 行脚本，0 个 npm 依赖，3 个服务端点。它的价值不在规模，而在每一个承诺都被写进了包体。
